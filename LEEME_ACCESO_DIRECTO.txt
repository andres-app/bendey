TIQUEPOS - ACCESO DIRECTO AL LOGIN
=================================

Cambios aplicados:
- Se eliminó el instalador web /install/.
- Se eliminó el control remoto externo.
- Se eliminó el control de licencia y mantenimiento remoto.
- Se eliminó la dependencia de storage/installed.lock.
- Al entrar al dominio, TiquePOS abre directamente el login.

IMPORTANTE:
Config/local.php contiene las credenciales privadas de la base de datos y las
claves de Cloudflare Turnstile. Este archivo no se incluye en el ZIP para no
exponer secretos.

Si ya tienes TiquePOS funcionando en el hosting:
1. Conserva tu Config/local.php actual.
2. Reemplaza los demás archivos por los de este paquete.
3. No necesitas storage/installed.lock.

Si es una instalación nueva:
1. Copia Config/local.php.example como Config/local.php.
2. Completa HOST, DB_USER, DB_PASS y DB_NAME.
3. Completa las claves de Turnstile y el dominio permitido.
4. Importa/configura la base de datos correspondiente.

No existe ya un flujo de instalación desde el navegador.
